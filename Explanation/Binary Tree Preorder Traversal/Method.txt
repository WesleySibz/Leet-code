To perform a preorder traversal of a binary tree, you can use both recursive and iterative approaches. In preorder traversal, you visit the root node first, then recursively visit the left subtree, and finally the right subtree.

Recursive Approach
The recursive approach is straightforward and involves calling the function recursively for the left and right subtrees.

Implementation (Recursive)

Iterative Approach
The iterative approach uses a stack to simulate the recursive call stack. This approach is useful when you want to avoid the overhead of recursive function calls.

Implementation (Iterative)

Explanation
TreeNode Class:
Defines a node in the binary tree with a value (val), a pointer to the left child (left), and a pointer to the right child (right).

Recursive Approach:
The preorderTraversal method defines a helper function preorder that takes a node as an argument.

If the node is None, return an empty list.

Recursively call preorder on the left subtree and the right subtree, and concatenate the results with the current node's value.

Iterative Approach:
The preorderTraversal method initializes a stack with the root node and an empty list output to store the traversal result.

Use a while loop to process nodes from the stack:
Pop a node from the stack.

If the node is not None, append its value to output.

Push the right child and then the left child of the node onto the stack (so that the left child is processed first).
