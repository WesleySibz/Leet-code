To perform an inorder traversal of a binary tree, you can use both recursive and iterative approaches. 
Inorder traversal visits nodes in the following order: left subtree, root node, right subtree.

Recursive Approach
The recursive approach is straightforward and involves calling the function recursively for the left subtree, 

then visiting the root node, and finally calling the function recursively for the right subtree.



Explanation
Recursive Approach:
Define a helper function inorder that takes a node as an argument.

If the node is None, return an empty list.

Recursively call inorder on the left subtree, visit the root node, and recursively call inorder on the right subtree.

Concatenate the results and return the final list.

Iterative Approach:
Initialize an empty list result to store the traversal result and an empty stack stack to simulate the recursive call stack.

Use a pointer current to traverse the tree.

While current is not None or the stack is not empty:

Traverse to the leftmost node, pushing each node onto the stack.

Pop a node from the stack, visit it by appending its value to result, and move to its right subtree.

Return the result list.


Example Usage
Example 1:
Input: root = [1, null, 2, 3]

Output: [1, 3, 2]

Explanation: The inorder traversal visits nodes in the order: left subtree, root node, right subtree.

Example 2:
Input: root = [1, 2, 3, 4, 5, null, 8, null, null, 6, 7, 9]

Output: [4, 2, 6, 5, 7, 1, 3, 9, 8]

Explanation: The inorder traversal visits nodes in the order: left subtree, root node, right subtree.

Example 3:
Input: root = []

Output: []

Explanation: The tree is empty, so the result is an empty list.

Example 4:
Input: root = [1]

Output: [1]

Explanation: The tree has only one node, so the result is a list with that single node.

making it suitable for environments with limited stack space.
