To find all customers who never placed an order, 
you can use a LEFT JOIN between the Customers table and the Orders table.

Then, filter the results to include only those customers who do not have a 
corresponding entry in the Orders table.

Explanation
SELECT Clause:

Select the name column from the Customers table and alias it as Customers.
FROM Clause:
Specify the Customers table with an alias c.

LEFT JOIN Clause:
Perform a left join with the Orders table with an alias o.

Join the tables on the condition that the id of the Customers 
table matches the customerId of the Orders table.

WHERE Clause:
Filter the results to include only those rows where o.customerId is NULL, 
indicating that the customer has not placed any orders.

Example Usage
Given the example tables:

Customers Table:

+----+-------+
| id | name  |
+----+-------+
| 1  | Joe   |
| 2  | Henry |
| 3  | Sam   |
| 4  | Max   |
+----+-------+

Orders Table:

+----+------------+
| id | customerId |
+----+------------+
| 1  | 3          |
| 2  | 1          |
+----+------------+

Output:

+-----------+
| Customers |
+-----------+
| Henry     |
| Max       |
+-----------+

Explanation of the Output
Henry (id = 2) and Max (id = 4) do not have corresponding entries in the Orders table.

The query performs a left join and filters to include only those customers who do not 
have a matching customerId in the Orders table.

Summary
This query efficiently finds all customers who never placed an order by using a LEFT JOIN 
and filtering based on the absence of matching entries in the Orders table. 
The result is returned in any order, as specified in the problem statement.
