To convert a given integer columnNumber to its corresponding column title as it appears in an Excel sheet, 
you can use a method similar to converting a number to a different base. 
In this case, the base is 26, and the characters used are 'A' to 'Z'.

Steps
Initialize an Empty String:

This string will store the resulting column title.

Convert the Number:

While columnNumber is greater than 0:
Subtract 1 from columnNumber to handle the 1-based indexing.

Find the remainder when columnNumber is divided by 26. This remainder corresponds to a character in the range 'A' to 'Z'.

Convert the remainder to the corresponding character and prepend it to the result string.

Update columnNumber by performing integer division by 26.

Return the Result:

Return the resulting column title string.
