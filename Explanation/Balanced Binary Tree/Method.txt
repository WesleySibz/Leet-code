To determine if a binary tree is height-balanced, you can use a recursive approach. 
A binary tree is considered height-balanced if the depth of the two subtrees of every node never differs by more than one.

Steps
Base Case: If the tree is empty, it is height-balanced.

Recursive Case:
Calculate the height of the left and right subtrees.

Check if the left and right subtrees are height-balanced.

The tree is height-balanced if the left and right subtrees are height-balanced and the difference in their heights is not more than one.

Explanation
TreeNode Class:
Defines a node in the binary tree with a value (val), a pointer to the left child (left), and a pointer to the right child (right).

isBalanced Method:
The isBalanced method takes the root of the binary tree and returns True if the tree is height-balanced, otherwise False.

Height Helper Function:
The height function is a nested function within isBalanced that calculates the height of a node.

If the node is None, it returns 0.

Recursively calculates the height of the left and right subtrees.

If either subtree is not height-balanced (returns -1) or the difference in their heights is more than one, it returns -1.

Otherwise, it returns the maximum height of the left and right subtrees plus one.

Return the Result:
The isBalanced method calls the height function with the root of the tree.

If the height function returns -1, the tree is not height-balanced, otherwise, it is height-balanced.

Example 1:
Input: root = [3, 9, 20, null, null, 15, 7]

Output: true

Explanation: The tree is height-balanced.

Example 2:
Input: root = [1, 2, 2, 3, 3, null, null, 4, 4]
