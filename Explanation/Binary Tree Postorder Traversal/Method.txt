To perform a postorder traversal of a binary tree, you can use both recursive and iterative approaches. 
In postorder traversal, you visit the left subtree first, then the right subtree, and finally the root node.

Recursive Approach
The recursive approach is straightforward and involves calling the function recursively for the left and right subtrees, 
and then visiting the root node.

Implementation (Recursive)


Iterative Approach
The iterative approach uses a stack to simulate the recursive call stack. 
This approach is useful when you want to avoid the overhead of recursive function calls.

Implementation (Iterative)


Explanation
TreeNode Class:
Defines a node in the binary tree with a value (val), a pointer to the left child (left), and a pointer to the right child (right).

Recursive Approach:
The postorderTraversal method defines a helper function postorder that takes a node as an argument.

If the node is None, return an empty list.

Recursively call postorder on the left subtree and the right subtree, 
and concatenate the results with the current node's value at the end.

Iterative Approach:
The postorderTraversal method initializes a stack with the root node and an empty list output to store the traversal result.

Use a while loop to process nodes from the stack:
Pop a node from the stack.

If the node is not None, append its value to output.

Push the left child and then the right child of the node onto the stack (so that the right child is processed first).

Reverse the output list to get the correct postorder traversal.
