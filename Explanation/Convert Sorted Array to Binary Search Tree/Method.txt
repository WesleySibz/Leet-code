Explanation of the Code
The code converts a sorted array into a height-balanced binary search tree (BST). 
A height-balanced BST is a binary tree in which the depth of the two subtrees of every node never differs by more than one.

Steps
Base Case: If the array is empty, return None.

Recursive Case:
Choose the middle element of the array as the root node.

Recursively build the left subtree using the left half of the array.

Recursively build the right subtree using the right half of the array.

Return the Root: Return the root node of the BST.

sortedArrayToBST Method:
The method sortedArrayToBST takes a sorted list of integers nums and returns the root of a height-balanced BST.

If the input array nums is empty, it returns None.

Helper Function:
The helper function is a nested function within sortedArrayToBST that takes two parameters: left and right, 
representing the current subarray bounds.

If left is greater than right, it means the subarray is empty, so it returns None.

It calculates the middle index mid of the current subarray and creates a root node with the middle element.

It recursively builds the left subtree using the left half of the subarray (left to mid - 1).

It recursively builds the right subtree using the right half of the subarray (mid + 1 to right).

It returns the root node of the BST.

Return the Root:
The sortedArrayToBST method calls the helper function with the initial bounds of the entire array (0 to len(nums) - 1).

It returns the root node of the constructed BST.
